BuildLog
학습한 내용과 해결한 오류를 기록하는 서비스입니다.
git으로 변경이력을 관리합니다

# 무엇을 할 수 있나요?

- **공부 기록**: 오늘 공부한 내용을 제목과 내용으로 남기고 검색합니다.
- **할 일**: 앞으로 할 일을 적고 끝내면 체크합니다. 전체 / 남은 일 / 완료한 일로 나누어 봅니다.
- **오류 기록**: 오류와 해결 방법을 모아 둡니다. 아직 못 푼 오류도 먼저 저장하고, 해결하면 방법을 적습니다.
- **공개 / 비공개**: 모든 기록은 처음에 나만 볼 수 있는 비공개입니다. 원하는 기록만 공개로 바꿉니다.
- **공개 기록 모아보기**: 공개된 기록을 읽고 검색합니다. 공부 기록과 오류 기록에는 댓글과 좋아요를 남기고, 공개 기록과 댓글은 신고할 수 있습니다.
- 컴퓨터와 휴대폰에서 모두 사용할 수 있습니다.

# 사용한 기술

화면은 React, 서버는 Python FastAPI, 데이터베이스는 개발·시험용 SQLite3와 실제 서비스용 Supabase(아직 연결 미확인)입니다.
